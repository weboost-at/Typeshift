# Security policy

## Reporting a vulnerability

Report a vulnerability in private, not in a public issue. On the repository's **Security** tab, choose
**Report a vulnerability**, or open <https://github.com/weboost-at/Typeshift/security/advisories/new>. The report
opens a draft advisory that only you and the maintainers can see.

Name the version of the package, what the weakness lets someone do, and the steps that show it.

## Supported versions

Typeshift is in alpha. A fix ships in the next release, and only the latest release gets one: earlier versions are
not patched.
